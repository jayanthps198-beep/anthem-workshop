# Anthem Workshop

A lightweight Python & Flask web application designed for interactive workshops, version control demonstrations, and hands-on Git workflows.

## 🚀 Features

- **Flask Backend:** Quick setup for lightweight local web serving.
- **HTML Templates:** Rendered user views built with clean, simple templates.
- **Git & GitHub Ready:** Includes pre-configured structure for learning branch management, conflict resolution, and remote deployment.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Framework:** Flask
- **Version Control:** Git & GitHub
