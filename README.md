## 📌 About the Project

**Anthem Workshop** is a lightweight web application developed using Python and Flask to present the Indian National Anthem through a simple and accessible web interface.

Created by **Jayanth PS**, the project demonstrates the fundamentals of Python web development, Flask routing, and HTML template rendering. It is designed as a beginner-friendly workshop project that combines simplicity, learning, and national pride.

## ✨ Features

- 🇮🇳 Displays the Indian National Anthem.
- 🌐 Simple and accessible web interface.
- ⚡ Lightweight Flask application.
- 🧩 HTML template-based rendering.
- 🚀 Easy local setup and execution.
- 🎓 Suitable for educational workshops and demonstrations.
